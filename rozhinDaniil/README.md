## Пара 2 — проект Expo, приветственный экран и навигация

**Что сделано:**
- Создан проект на Expo с TypeScript.
- Приветственный экран `src/screens/WelcomeScreen.tsx`: логотип, заголовок, подзаголовок и кнопка «Начать».
- Навигация на **expo-router**:
  - `src/app/_layout.tsx` — корневой `Stack` (экран приветствия → вкладки);
  - `src/app/index.tsx` — стартовый маршрут `/`, кнопка «Начать» делает `router.replace('/home')`, чтобы назад на приветствие вернуться было нельзя;
  - `src/app/(tabs)/_layout.tsx` — нижняя панель из 3 вкладок: **Главная**, **Счётчик**, **Профиль** (иконки Ionicons).
- Общий компонент-заглушка `src/components/PlaceholderScreen.tsx` для ещё не наполненных вкладок.

**Как работает expo-router (для защиты):**
- Маршрутизация **файловая**: каждый файл в `src/app/` — это экран, путь к файлу = URL маршрута (`home.tsx` → `/home`).
- `_layout.tsx` задаёт навигатор для своей папки: в корне — `Stack` (экраны друг над другом), в `(tabs)` — `Tabs` (нижние вкладки).
- Папка в скобках `(tabs)` — **группа**: она объединяет экраны под одним layout, но в URL не попадает (`/home`, а не `/(tabs)/home`).
- Переходы: `router.push()` добавляет экран в историю, `router.replace()` подменяет текущий, `<Link href="...">` — декларативная ссылка.
- Точка входа приложения — `"main": "expo-router/entry"` в `package.json`, плагин `expo-router` подключён в `app.json`.
- Под капотом expo-router использует React Navigation, просто экраны объявляются файлами, а не вручную через `createStackNavigator` и т.п.

## Пара 3 — состояние: `useState`, счётчик

**Что сделано:** вкладка **Счётчик** (`src/app/(tabs)/counter.tsx`):
- состояние хранится в `useState(0)`;
- кнопки «+» и «−», обновление через функциональную форму `setCount(prev => ...)`;
- счётчик не уходит ниже нуля — `Math.max(0, prev - 1)`, а кнопка «−» на нуле `disabled` и визуально приглушена;
- кнопка **Reset** сбрасывает значение в 0;
- обратная связь при нажатии через стиль `pressed` у `Pressable`, подписи `accessibilityLabel`.
