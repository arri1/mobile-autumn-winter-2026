## Цель

Освоить локальное состояние функционального компонента в React Native через хук `useState`: хранение значения, его обновление по событиям и перерисовку интерфейса.

## Требования

| # | Требование | Статус |
|---|------------|--------|
| 1 | Экран «Счётчик» доступен отдельной вкладкой в нижней навигации | ✅ |
| 2 | Текущее значение хранится в `useState`, начальное значение — `0` | ✅ |
| 3 | Кнопка «+» увеличивает значение на 1 | ✅ |
| 4 | Кнопка «−» уменьшает значение на 1 | ✅ |
| 5 | Значение не может стать отрицательным | ✅ `Math.max(0, prev - 1)` |
| 6 | Кнопка «−» неактивна (`disabled`), когда значение равно 0, и визуально это видно | ✅ |
| 7 | Кнопка «Reset» сбрасывает значение в 0 | ✅ |
| 8 | Нажатие на кнопки даёт визуальный отклик | ✅ стиль `pressed` у `Pressable` |

## Реализация

```tsx
const [count, setCount] = useState(0);

const increment = () => setCount((prev) => prev + 1);
const decrement = () => setCount((prev) => Math.max(0, prev - 1));
const reset = () => setCount(0);

const canDecrement = count > 0;
```

- **Функциональное обновление** `setCount(prev => ...)` — новое значение считается от актуального предыдущего, а не от значения из замыкания. Это важно, если несколько обновлений произойдут до перерисовки (например, быстрые нажатия).
- **Двойная защита от отрицательных значений:** `Math.max` в логике + `disabled` на кнопке в UI. Даже если кнопку как-то нажать, состояние не уйдёт ниже нуля.
- `canDecrement` — **производное значение**, вычисляется из `count` при каждом рендере, отдельный `useState` для него не нужен.

## Ключевые понятия (для защиты)

- `useState` возвращает пару `[значение, функция-сеттер]`; вызов сеттера планирует перерисовку компонента с новым значением.
- Состояние нельзя менять напрямую (`count++`) — React не узнает об изменении и не перерисует экран.
- Состояние локально для компонента: при уходе с вкладки и возврате значение сохраняется, пока экран не размонтирован навигатором.

## Проверка

1. `cd my-app && npx expo start`, открыть приложение, нажать «Начать», перейти на вкладку «Счётчик».
2. На старте показано `0`, кнопка «−» бледная и не нажимается.
3. Нажать «+» три раза → `3`; «−» один раз → `2`.
4. Нажать «Reset» → `0`, кнопка «−» снова неактивна.
