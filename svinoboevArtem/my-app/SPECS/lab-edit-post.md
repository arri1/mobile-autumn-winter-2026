# Доп. · Редактирование и удаление своего поста (PUT, DELETE)

```text
Цель: на экране поста можно изменить или удалить свой пост.

Свой пост: в заголовке есть фамилия «Свинобоев» (isMyPost в src/api.ts). У чужих кнопок нет.
Редактирование: «Изменить» → та же PostFormScreen с параметром { id }; поля заполняются через getPost(id);
  «Сохранить» → PUT /posts/{id} (updatePost) → назад, экран поста перезагружается.
Удаление: «Удалить» → Alert-подтверждение → DELETE /posts/{id} (deletePost) → назад к списку.
Состояния: во время запроса кнопки disabled («Удаление…» / «Отправка…»); ошибка → Alert.
Не делаем: правку и удаление чужих постов, авторизацию.
```

Файлы: `src/screens/PostViewScreen.tsx`, `src/screens/PostFormScreen.tsx`.
