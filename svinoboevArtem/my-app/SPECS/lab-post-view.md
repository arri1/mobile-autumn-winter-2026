# Пара 3 · Лаба: просмотр одного поста

```text
Цель: экран PostViewScreen показывает один пост с API курса.

Стек: Expo + TypeScript, fetch, useEffect, useState, @react-navigation/native-stack.
Источник: GET http://185.233.185.109:8080/api/v1/posts/{id} (функция getPost из src/api.ts).
Навигация: стек внутри вкладки «Посты»: тап по карточке → PostView с параметром { id }.
UI: заголовок, полный текст, дата (и дата изменения, если пост правили); «Назад» в шапке.
Состояния: загрузка → ActivityIndicator; ошибка / 404 → текст + «Назад».
Готово, если: в Expo Go открывается конкретный пост, id берётся из навигации.
```

## Как устроено

- Данные не берутся из списка — отдельный запрос `getPost(id)`.
- Зависимость эффекта `[id]` (+ фокус экрана): открыли другой пост — пришли новые данные; вернулись после редактирования — данные свежие.
- Флаг `cancelled` в cleanup: если ушли до ответа сервера, `setState` не вызывается.
- Параметры навигации типизированы (`src/navigation/types.ts`), без `any`.

Файл: `src/screens/PostViewScreen.tsx`.
