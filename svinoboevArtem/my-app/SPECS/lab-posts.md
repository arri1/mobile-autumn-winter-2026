# Пара 3 · Лаба: просмотр списка постов

```text
Цель: экран PostsScreen показывает посты с API курса.

Стек: Expo + TypeScript, fetch, useEffect, useState, FlatList.
Источник: GET http://185.233.185.109:8080/api/v1/posts (функция getPosts из src/api.ts).
UI: карточка = заголовок (жирный) + текст + дата; мои посты помечены «мой».
Состояния: загрузка → ActivityIndicator; ошибка → текст + «Повторить»; пусто → «Постов нет».
Готово, если: список грузится в Expo Go, есть все три состояния, экран во вкладке «Посты».
Не делаем: авторизацию, библиотеки (axios, react-query).
```

## Как устроено

- `fetch` вызывается в `useEffect(..., [])`, а не в теле компонента: иначе `setPosts` → рендер → новый `fetch` → бесконечный цикл. Сам эффект не `async` — внутри вызывается async-функция.
- `BASE_URL` и функции запросов вынесены в `src/api.ts`; `res.ok` проверяется, текст ошибки сервера (`{ "error": … }`) показывается пользователю.
- `FlatList` с `keyExtractor={(item) => String(item.id)}`.
- Плюсы: pull-to-refresh (`refreshing` + `onRefresh`), тихое обновление при возврате на экран (после создания/удаления поста).

Файлы: `src/api.ts`, `src/screens/PostsScreen.tsx`.
