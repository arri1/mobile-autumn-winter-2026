# Доп. · Создание поста (POST)

```text
Цель: PostFormScreen создаёт пост через API.

UI: TextInput «Заголовок», TextInput «Текст» (multiline), кнопка «Опубликовать»; открывается «+» в шапке списка.
Поведение:
- пустые поля → кнопка disabled;
- во время отправки кнопка disabled, подпись «Отправка…»;
- успех → поля очищаются, Alert «Готово», возврат к списку (список обновляется);
- ошибка → Alert с текстом ошибки.
Ограничения: fetch через createPost из src/api.ts, без библиотек форм.
Готово, если: пост появляется в списке и в Swagger.
```

База общая: к заголовку автоматически добавляется фамилия «Свинобоев», чужие посты не трогаю.

Файл: `src/screens/PostFormScreen.tsx`.
