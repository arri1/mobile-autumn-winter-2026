# Пара 1 · Мини-спека (SDD): экран-счётчик на useState

**Цель:** учебный экран, на котором число меняется кнопками; разобраться, как `useState` перерисовывает экран.

**Стек и ограничения:** Expo SDK 57 + TypeScript, только `useState` и `StyleSheet`, без сторонних библиотек.

**Acceptance criteria (готово, если):**
- [x] на экране число, старт — 0
- [x] кнопка «+» увеличивает на 1
- [x] кнопка «−» уменьшает на 1, но не ниже 0
- [x] кнопка «Reset» возвращает 0
- [x] экран в отдельном файле, код могу объяснить на защите

**Не делаем:** сохранение между запусками (AsyncStorage), сервер, анимации, Redux/Zustand.

Реализация — [`lab-usestate.md`](./lab-usestate.md), `src/screens/CounterScreen.tsx`.
