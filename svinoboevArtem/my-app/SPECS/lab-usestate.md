# Пара 3 · Лаба useState — счётчик

```text
Цель: экран-счётчик на useState.

Стек: Expo + TypeScript.
Экран CounterScreen на отдельной вкладке «Счётчик».
UI: число по центру; кнопки +, −, Reset.
Поведение: старт 0; − не ниже 0; Reset → 0.
Ограничения: только useState + StyleSheet; без библиотек.
Готово, если: три кнопки работают, экран в Tabs, код объясним.
Не делаем: AsyncStorage, сервер, анимации, Redux/Zustand.
```

## Как устроено

- `const [count, setCount] = useState(0)` — `count` только читаем, меняем через `setCount`, после него экран перерисовывается.
- Обновления функциональные: `setCount((c) => c + 1)` — React передаёт актуальное значение, даже если нажатия идут подряд.
- «−» — `Math.max(0, c - 1)`; при 0 кнопка ещё и `disabled`, чтобы было видно, что ниже нельзя.

Файл: `src/screens/CounterScreen.tsx`.
