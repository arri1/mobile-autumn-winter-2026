# Управляемый TextInput

Цель — связать поле ввода с состоянием React.

- [x] Экран «Имя» открывается из вкладки «Лабы».
- [x] `value` читает строку из useState, а `onChangeText` обновляет её.
- [x] Приветствие обновляется при вводе. Пустая строка или пробелы дают «Привет!».

Границы — одна строка с именем. Данные хранятся в памяти экрана.
