# Просмотр поста

Цель — открыть выбранный пост и прочитать полный текст.

- [x] Expo Router передаёт id из карточки списка.
- [x] getPost выполняет отдельный GET /api/v1/posts/{id} при открытии или смене id.
- [x] Экран показывает заголовок, дату и полный текст. Для загрузки, ошибки и 404 предусмотрены сообщения.
- [x] По кнопке «К постам» можно вернуться к списку.

Границы — просмотр поста по id.
