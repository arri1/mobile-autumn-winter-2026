# Счётчик на useState

Цель — показать, как состояние React меняет экран.

- [x] Экран открывается во вкладке «Лабы» и показывает 0 при первом входе.
- [x] Плюс прибавляет 1, минус вычитает 1 до нижней границы 0.
- [x] «Сбросить» возвращает значение к 0.
- [x] Значение хранится в useState, стили заданы через StyleSheet.

Границы — локальное состояние текущего сеанса. Хранилище, сервер и анимации выходят за рамки лабы.
