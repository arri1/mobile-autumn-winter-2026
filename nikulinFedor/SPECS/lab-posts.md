# Список постов

Цель — прочитать посты с учебного API и показать их во вкладке «Посты».

- [x] getPosts отправляет GET /api/v1/posts, а экран запускает загрузку в эффекте.
- [x] FlatList показывает заголовок, краткий текст и дату. Ключ элемента — id.
- [x] Для загрузки, ошибки и пустого ответа предусмотрены отдельные состояния. Кнопка «Повторить» запускает запрос заново.
- [x] Нажатие на карточку открывает отдельный экран поста.

Границы — чтение публичных постов. Создание, редактирование, удаление и вход в аккаунт выходят за рамки лабы.
