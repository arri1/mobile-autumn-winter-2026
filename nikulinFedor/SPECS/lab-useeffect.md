# Таймер на useEffect

Цель — запустить побочный эффект и освободить его ресурсы при уходе с экрана.

- [x] «Таймер» открывается из вкладки «Лабы» и начинает отсчёт с нуля.
- [x] useEffect создаёт интервал и прибавляет секунду через функциональное обновление состояния.
- [x] Cleanup вызывает clearInterval при уходе с экрана. Каждый новый вход начинает новый отсчёт.

Границы — секунды, проведённые на экране. Таймер работает только во время просмотра.
