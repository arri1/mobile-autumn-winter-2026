# Кампус СВФУ

Учебный проект для навигации по корпусам Северо-Восточного федерального университета в Якутске.

Изучаю мобильную разработку, чтобы делать приложения, которые помогают студентам в повседневных задачах, например найти аудиторию перед парой.

## Что умеет приложение

- Показывает интерактивные 3D-модели КФЕН, ГУК и УЛК. Модель можно вращать жестом или кнопками.
- Показывает схемы всех семи этажей КФЕН сверху. Можно переключать этажи, прокручивать схему и выбирать помещения на ней.
- Находит помещение по номеру и открывает его этаж. Приложение строит путь по коридорам от ближайшей лестницы и пересчитывает его, если выбрать другую лестницу.

На схемах отмечено 191 помещение. Маршрут доступен для 185 помещений с нанесёнными дверями и проходами. Положение дверей восстановлено приблизительно по снимкам, поэтому на месте стоит сверяться с указателями. Для ГУК и УЛК доступны модели корпусов.

## Как запустить

Из корня репозитория с установленным Node.js 22.13 или новее выполни:

```bash
cd nikulinFedor
npm ci
npm run web
```

Для запуска в Expo Go используй `npm start` и клиент, совместимый с Expo SDK 57.

## Как проверить

1. Выбери **КФЕН** и нажми **Войти в КФЕН**.
2. Введи `324` и выбери результат. Откроется третий этаж с маршрутом до аудитории.
3. Выбери другую лестницу и проверь, что начало пути сместилось. Кнопка **Весь этаж** открывает обзорную схему.
4. Найди `626`, чтобы проверить переход на шестой этаж. Для номера `999` приложение покажет, что подтверждённых данных нет.

Проверки проекта запускаются командами `npm run lint` и `npx tsc --noEmit`.
